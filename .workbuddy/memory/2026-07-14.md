## Pandora → Web 适配

- 在 `Models/Event.cs` 中新增 4 个事件：`AssistantMessageStartEvent`、`ReasoningEndEvent`、`ContentEndEvent`、`ToolCallEndEvent`
- `AgentUsageChangedEvent` 添加 `CacheHitRate` 字段
- `AiService.cs`：流式过程中检测 reasoning→content 切换，自动触发 `ReasoningEndEvent`
- `Session.cs`：在 CompleteChat 循环中触发 `AssistantMessageStartEvent`（每轮 AI 开始前）、`ContentEndEvent`（流式完成后）、`ToolCallEndEvent`（工具执行后）、`AgentUsageChangedEvent`（usage 累计后）
- 新增 `WebSocket/` 目录结构：
  - `Protocol/WsProtocol.cs` — 30+ 种 WebSocket 消息 DTO 及序列化
  - `Server/WsServer.cs` — HttpListener + WebSocket accept 循环
  - `Server/WsConnection.cs` — 单连接收发管理（SemaphoreSlim 线程安全）
  - `Handler/WsMessageHandler.cs` — 16 种客户端消息分发（session CRUD、send_message、provider CRUD、安全确认等）
  - `Bridge/SessionBridge.cs` — EventBus→WebSocket 桥接，安全确认 TCS 阻塞等待
- `Program.cs` 改为 WebSocket 服务器入口（监听 `http://localhost:9527/`，路径过滤 `/ws`）
- 编译通过 0 Error 0 Warning，服务器启动正常
- 不改变架构：所有 WebSocket 代码为新增层，Agent/Event/Interfaces/Models 中仅为事件定义和触发点的增量修改
